# Code the Vacation with Mortoti

**Code the Vacation** is a two-month Python boot camp I organized and taught.  
We meet twice a week, taking absolute beginners step by step into the world of programming with Python.  

## 📅 Boot Camp Structure
- Duration: 2 months  
- Meetings: Twice a week  
- Tutor: Mortoti (Organizer + Instructor)  

## 📖 Sessions Covered

### Session 1
- Introduction to Python  
- Variables  
- Data Types  
- f-Strings  
- String Methods  

### Session 2
- Taking Input  
- Comparison Operators  
- Logical Operators  
- Arithmetic Operators  
- String Conversion  

### Session 3
- If Statements (`if`, `elif`, `else`)  
- Comparison Operators Review  
- Logical Conditions in Decisions  
- Even/Odd Number Check  
- Temperature Example (Practical Application)

(More sessions will be added as we progress 🚀)

## 🚀 Goal
By the end of the boot camp, participants will have hands-on experience with Python fundamentals, problem-solving, and small projects that solidify their learning.
